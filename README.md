# AVL Tree

C implementation of an AVL Tree in ISO C (c99). This implementation have zero-dependencies. 

## Usage

Copy the files *avl.c* and *avl.h* to your development directory and include avl.h where you want to use these functions.
See the file example.c to view an example of use.
